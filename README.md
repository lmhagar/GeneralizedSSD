# GeneralizedSSD
Supplementary code for Economical Experimental Design with Generalized Posteriors manuscript 

There are four code files for this manuscript.

    01_ph_models: reproduces the results in Section 5.1 of the main text
    02_median_mix: reproduces the results in Section 5.2 of the main text
	03_details_orvac: functions for the example in Section 6 of the main text
	04_run_orvac: reproduces the results in Section 6 of the main text

There is also the "jags_gbi.txt" file that is used to implement JAGS for the median example in Section 5.2.
